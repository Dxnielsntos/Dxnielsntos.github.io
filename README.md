# Carta Digital Interactiva 💌

Una pequeña aplicación web interactiva diseñada para ser una carta digital animada. Este proyecto combina diseño Front-end y animaciones CSS para crear una experiencia de usuario cálida y sorpresiva.

## ✨ Características Principales
* **Diseño UI Romántico:** Fondo con degradado radial y elementos flotantes.
* **Arte CSS (CSS Art):** Corazones plateados creados 100% con código CSS y pseudo-elementos, con animación de latido (`pulse`).
* **Animaciones Interactivas:** 
  * Globos flotantes continuos en el fondo.
  * Efecto 3D de apertura en la solapa del sobre al hacer clic en el sello de cera.
  * Transición de expansión para facilitar la lectura de la carta.
* **Multimedia:** Integración de efectos de sonido (papel) que se activan mediante JavaScript al interactuar con el sobre.
* **Composición Visual:** Collage de imágenes posicionadas de manera absoluta alrededor del elemento central para enmarcar la carta.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica del sobre y la carta.
* **CSS3:** Animaciones (`@keyframes`), transiciones, variables, pseudo-elementos y uso de Google Fonts (Montserrat y Dancing Script).
* **JavaScript (Vanilla):** Lógica de eventos (Event Listeners) para manipular las clases (DOM) y reproducir el audio.
